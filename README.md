# ADAG-project---Grupo-4
Repositório TCC - Curso Técnico Desenvolvimento de Sistemas
Plataforma Web de Divulgação de Produtos para Piscina

Este repositório contém o desenvolvimento do ADAG, um site criado com o objetivo de apresentar e divulgar produtos relacionados a piscinas, como equipamentos, acessórios e itens de manutenção.

A proposta da plataforma é reunir informações sobre esses produtos em um único lugar, facilitando para que os usuários encontrem opções de compra e conheçam diferentes tipos de equipamentos.

🎯 Objetivo do Projeto

O principal objetivo do ADAG é desenvolver um site web voltado para a divulgação de produtos para piscina, oferecendo uma navegação simples e organizada para os usuários.

Entre os objetivos do projeto estão:

Divulgar equipamentos e acessórios utilizados em piscinas;

Organizar produtos por categorias para facilitar a navegação;

Exibir anúncios e recomendações de produtos;

Criar um site visualmente simples e fácil de usar;

Colocar em prática conhecimentos de desenvolvimento web.

🧩 Funcionalidades previstas

Algumas das funcionalidades planejadas para o site incluem:

Página inicial com apresentação do projeto;

Listagem de produtos relacionados a piscinas;

Páginas com informações e detalhes sobre os produtos;

Organização por categorias ou tipos de produtos;

Layout responsivo para funcionamento em diferentes dispositivos.

🛠️ Tecnologias utilizadas

Durante o desenvolvimento do projeto podem ser utilizadas as seguintes tecnologias:

HTML5 — Estrutura das páginas do site

CSS — Estilização e organização do layout

JavaScript — Funcionalidades e interatividade

Python (se necessário)

Backend

Banco de dados

As tecnologias utilizadas podem ser ajustadas conforme o andamento do projeto.
